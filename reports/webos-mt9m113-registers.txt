==========================================
  MCU Variable Dump (via XDMA 0x098C/0x0990)
==========================================

=== MIPI Control Registers ===
OUTPUT_CONTROL (0x3400) = 0x782E
  - data_type bits[15:10] = 0x1E (YUV422)
  - This controls MIPI output format
CUSTOM_SHORT_PKT (0x3404) = 0x0000
  - NO Frame Start/End short packets!

=== Sequencer MCU Variables ===
SEQ_CMD (0xA103) = 0x0006 (REFRESH_MODE)
SEQ_STATE (0xA104) = 0x0003 (Streaming)
SEQ_CAP_MODE (0xA115) = 0x0006

=== Mode Context A (Preview) ===
MODE_OUTPUT_WIDTH_A (0x2703) = 0x0280 (640)
MODE_OUTPUT_HEIGHT_A (0x2705) = 0x01E0 (480)
MODE_SENSOR_READ_MODE_A (0x2717) = 0x046C
  - xy_bin_en (bit 10) = 1 (2x2 binning)
  - x_odd_inc = 3 (skip columns)
  - y_odd_inc = 3 (skip rows)
MODE_SENSOR_FRAME_LENGTH_A (0x271F) = 0x032E (814)
MODE_OUTPUT_FORMAT_A (0x2755) = 0x0000 (YUV, no swap)

=== Mode Context B (Capture/Full Res) ===
MODE_OUTPUT_WIDTH_B (0x2707) = 0x0500 (1280)
MODE_OUTPUT_HEIGHT_B (0x2709) = 0x0400 (1024)
MODE_SENSOR_READ_MODE_B (0x272D) = 0x0024 (no binning)
MODE_OUTPUT_FORMAT_B (0x2757) = 0x0006

=== CRITICAL FINDINGS ===
1. CUSTOM_SHORT_PKT = 0x0000 confirms NO MIPI FS/FE packets
2. Preview uses 2x2 binning (1280x1024 -> 640x512 sensor, output 640x480)
3. OUTPUT_CONTROL = 0x782E controls MIPI YUV422 output
4. Sensor is in streaming state (SEQ_STATE=3)

VIDEO mode uses OUTPUT_CONTROL = 0x7A08 which is the expected
MIPI configuration (data_type=0x1E, mipi_en=1, LP clock mode)

==========================================
  PHOTO CAPTURE MODE - Sensor Transitions
  Date: 2026-03-31
==========================================

During photo capture, the sensor goes through rapid state changes:

=== OUTPUT_CONTROL Transitions ===
- 0x7A08 = Normal streaming (MIPI enabled)
- 0x7A00 = Brief transition (MIPI output disabled, bit 3 = 0)

=== Sequencer Command Sequence ===
SEQ_CMD values seen during capture:
- 0x0000 = Idle/complete
- 0x0001 = RUN command
- 0x0002 = Capture mode command  
- 0x0005 = REFRESH command

=== Sequencer State Changes ===
SEQ_STATE values:
- 0x0003 = Normal streaming
- 0x0007 = Capture/processing state
- 0x0002 = Transition state

=== Other Register Changes ===
- RESET_REGISTER: 0x12CC <-> 0x12C8 (bit 2 toggles)
- SEQ_CAP_MODE: 0x0030 (preview) <-> 0x0000 (capture)

=== KEY INSIGHT ===
Photo capture in webOS stays in Context A (640x480) and doesn't
switch to Context B (1280x1024 full resolution). Photos appear
to use the preview stream with software post-processing.

The sensor briefly disables MIPI output (0x7A00) during mode
transitions, then re-enables it (0x7A08).
