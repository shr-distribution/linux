# Audio Test Samples

Self-contained test WAVs for `scripts/test-audio.sh`. Generated by the
inline Python in this repo's generation script so we don't depend on the
HP doctor305 rootfs being present at a hardcoded path.

| File | Duration | Format | Purpose |
|------|----------|--------|---------|
| `sine-440hz-1s.wav` | 1.0 s | 48 kHz S16 stereo, -3 dBFS | Basic "is anything coming out?" tone. Same on both channels. |
| `stereo-1khz-440hz-1s.wav` | 1.0 s | 48 kHz S16 stereo, -3 dBFS | 1 kHz on L, 440 Hz on R. Detects channel swap and mono-bridging. |
| `sweep-200-2000hz-500ms.wav` | 0.5 s | 48 kHz S16 stereo, -3 dBFS | Linear sweep. Hearable artefacts at sweep boundaries reveal DMA gaps or codec-side EQ glitches. |

All files are 192 kB or less so they're cheap to ship through the repo and SCP.

## Regenerate

To rebuild after editing the parameters, re-run the Python from
`scripts/test-audio.sh` (the `generate_samples_if_missing` helper) or
manually:

```bash
python3 -c "$(sed -n '/PYTHON GEN BEGIN/,/PYTHON GEN END/p' scripts/test-audio.sh)"
```
